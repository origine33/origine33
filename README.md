### 🖨️ Printer Agent &nbsp;·&nbsp; <sub>fleet monitoring</sub> &nbsp;`private`
Turned an existing PrinterLogic install into a full monitoring system: SNMP polling for toner/paper/error state → a live **Datadog** dashboard, automatic Slack alerts and daily PDF reports, and a Slack bot IT can just ask. No new hardware, no new paid software.
